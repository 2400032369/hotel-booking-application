# Hotel Management System - Version A

A simple static HTML/CSS/JavaScript project for practicing Git and Gitflow.

## Features
- View sample hotel rooms
- Search rooms by name or type
- Demo booking button (no real booking or payment)
- Responsive layout

## Run locally
Open `index.html` in your browser. No installation or database is required.

## Suggested Gitflow exercise
1. Push the project to GitHub on `main`.
2. Create `develop`.
3. Create `feature/room-search`.
4. Make a small change in the feature branch and commit it.
5. Merge the feature branch into `develop`.
6. To practice a merge conflict, edit the same line in `README.md` on two branches, commit both changes, then merge one branch into the other.
